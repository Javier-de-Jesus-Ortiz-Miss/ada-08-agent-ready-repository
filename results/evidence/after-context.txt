FILE: SPEC.md 
 # Customer Search Specification

## Goal and Requirements Covered

I locate existing customer records from a local CLI with one term. I cover FR-01 through FR-06 and NFR-01 through NFR-03 from `REQUIREMENTS.md`.

## Scope

I query a fixed in-memory collection of fictional customers. I exclude creation, updates, deletion, persistence, HTTP endpoints, pagination, ranking and searches of other fields.

## Domain Model

I represent a customer with `Customer(id, name, email)`. I require `id` to be non-empty text; I preserve valid text verbatim, including whitespace, without trimming or new format rules. I reject a non-string or empty-string identifier at construction with `ValueError`. I leave name and email validation unchanged. I preserve frozen instances and read-only demo data.

I clarified the existing non-empty textual ID rule for CR-ADA08-01 before the baseline tag and either controlled run; I did not add it after seeing a failing implementation. I keep the archived original specification unchanged.

## Search Rules

I strip outer query whitespace, apply `str.casefold()` to the query and both searchable fields, and use substring membership in either name or email. I return each matching input record once even when both fields match. I preserve input order and interior query spaces. I accept any `Iterable[Customer]` and return a new list. I do not add accent normalization or fuzzy matching.

## Validation Rules

I require a textual query with at least one character after outer trimming. I require exactly one positional CLI argument. I distinguish query normalization from identifier preservation.

## Error Handling

I raise `ValueError` for invalid query input and invalid customer identifiers. I translate query errors to a useful Spanish message on stderr and CLI exit 2. I let argparse report missing or excess arguments with exit 2. I print `No se encontraron clientes.` with exit 0 for valid queries without matches. I print identifier, name and email for matches and return exit 0.

## Acceptance Criteria

- **AC-01 (FR-01):** I find customers by a term in either name or email.
- **AC-02 (FR-02):** I find a customer with a partial field fragment.
- **AC-03 (FR-03):** I retain matches when query casing changes, including Unicode casefold cases.
- **AC-04 (FR-04):** I show identifier, name and email in each CLI result.
- **AC-05 (FR-05):** I show the specified no-match message and exit 0.
- **AC-06 (FR-06):** I reject blank queries with a useful error and CLI exit 2.
- **AC-07 (NFR-01):** I execute automated acceptance tests with pytest, including input order and no duplicated output from matching both fields.
- **AC-08 (NFR-02):** I search without network, credentials or nonstandard runtime packages.
- **AC-09 (NFR-03):** I document Python, installation, run and test commands in README.
- **AC-10 (FR-04):** I reject non-text or empty identifiers at construction, preserve every non-empty textual identifier and keep customers immutable.

## Test Scenarios

I exercise name/email fragments, both-field matching, casing, Unicode sharp-s, order, generators, interior/outer spaces, absent records, blank and non-text queries, missing/extra CLI arguments, output fields and exit codes. I exercise invalid IDs, valid ID preservation and frozen-instance behavior for CR-ADA08-01.

## Constraints and Open Questions

I apply the constraints in `REQUIREMENTS.md`. I retain the resolved Q-01/Q-02 decisions there and introduce no unresolved product question in this task.

FILE: tests/test_search.py 
 import pytest

from customer_search import Customer, search_customers


CUSTOMERS = [
    Customer("1", "Ana López", "ana@example.com"),
    Customer("2", "Bruno Ana", "bruno@example.com"),
    Customer("3", "Carla", "carla@anadominio.com"),
]


def test_model_has_required_fields():
    assert (CUSTOMERS[0].id, CUSTOMERS[0].name, CUSTOMERS[0].email) == (
        "1", "Ana López", "ana@example.com"
    )


def test_partial_search_preserves_order():
    assert search_customers("an", CUSTOMERS) == CUSTOMERS


def test_partial_name_search():
    assert search_customers("Lóp", CUSTOMERS) == [CUSTOMERS[0]]


def test_partial_email_search():
    assert search_customers("dominio", CUSTOMERS) == [CUSTOMERS[2]]


def test_case_insensitive_and_trimmed():
    assert search_customers("  LÓPEZ  ", CUSTOMERS) == [CUSTOMERS[0]]


def test_customer_matching_both_fields_is_not_duplicated():
    assert search_customers("ana", CUSTOMERS).count(CUSTOMERS[0]) == 1


def test_no_matches_returns_empty_list():
    assert search_customers("inexistente", CUSTOMERS) == []


@pytest.mark.parametrize("term", ["", "   ", "\t\n"])
def test_empty_term_is_rejected(term):
    with pytest.raises(ValueError, match="no vacío"):
        search_customers(term, CUSTOMERS)


def test_non_text_term_is_rejected():
    with pytest.raises(ValueError, match="debe ser texto"):
        search_customers(None, CUSTOMERS)


@pytest.mark.parametrize("field", ["name", "email"])
@pytest.mark.parametrize("term", ["STRASSE", "  strasse  "])
def test_unicode_casefold_matches_name_and_email(field, term):
    # Unlike lower(), casefold() equates the German sharp s with ss.
    customer = Customer(
        "unicode",
        "Straße" if field == "name" else "Cliente",
        "straße@example.com" if field == "email" else "otro@example.com",
    )
    unrelated = Customer("other", "Bruno", "bruno@example.com")
    assert search_customers(term, [unrelated, customer]) == [customer]


@pytest.mark.parametrize(
    ("term", "expected_ids"),
    [("  ANA LÓPEZ  ", ["single"]), ("  ANA  LÓPEZ  ", ["double"])],
)
def test_search_preserves_internal_spaces(term, expected_ids):
    customers = [
        Customer("single", "Ana López", "uno@example.com"),
        Customer("double", "Ana  López", "dos@example.com"),
    ]
    assert [customer.id for customer in search_customers(term, customers)] == expected_ids


def test_search_accepts_generator_and_preserves_order():
    customers = (customer for customer in CUSTOMERS)
    assert search_customers("ANA", customers) == CUSTOMERS

 import os
import subprocess
import sys
from pathlib import Path

import pytest


def run_cli(*arguments):
    env = os.environ.copy()
    src = str(Path(__file__).resolve().parents[1] / "src")
    env["PYTHONPATH"] = os.pathsep.join(filter(None, [src, env.get("PYTHONPATH")]))
    return subprocess.run(
        [sys.executable, "-m", "customer_search", *arguments],
        capture_output=True,
        text=True,
        check=False,
        env=env,
    )


def test_cli_prints_customer_fields():
    result = run_cli("ana")
    assert result.returncode == 0
    assert "C001 | Ana López | ana.lopez@example.com" in result.stdout


def test_cli_reports_no_matches():
    result = run_cli("inexistente")
    assert result.returncode == 0
    assert result.stdout.strip() == "No se encontraron clientes."


@pytest.mark.parametrize("term", ["", "   ", "\t\n"])
def test_cli_rejects_blank_term(term):
    result = run_cli(term)
    assert result.returncode == 2
    assert "Error:" in result.stderr
    assert "no vacío" in result.stderr
    assert result.stdout == ""


def test_cli_requires_exactly_one_argument():
    for arguments in [(), ("ana", "bruno")]:
        result = run_cli(*arguments)
        assert result.returncode == 2
        assert "usage:" in result.stderr


def test_cli_trims_outer_spaces_and_preserves_inner_spaces():
    result = run_cli("  ANA LÓPEZ  ")
    assert result.returncode == 0
    assert result.stdout.strip() == "C001 | Ana López | ana.lopez@example.com"
    assert result.stderr == ""

    'results/evidence/functional-baseline.json',
)
# I intentionally do not require test_model_validation.py before the controlled change.
HEADINGS = {
    'AGENTS.md': ('Read First', 'Sources of Truth', 'Repository Map', 'Standard Commands',
                  'Change Rules', 'Safety and Permissions', 'Stop Conditions', 'Definition of Done'),
    'docs/REPO_MAP.md': ('Entry Points', 'Tests', 'Change Guide', 'Do Not Edit Directly'),
    'TASK_UNDER_TEST.md': ('Goal', 'Requirements Covered', 'Verification', 'Constraints'),
    'results/before-agent-run.md': ('Run Context', 'Clarification Questions', 'Repository Exploration',
                                   'Incorrect Assumptions', 'Failed / Unknown Commands',
                                   'Out-of-Scope Changes', 'Validation Evidence', 'Final Result'),
    'results/after-agent-run.md': ('Run Context', 'Clarification Questions', 'Repository Exploration',
                                  'Incorrect Assumptions', 'Failed / Unknown Commands',
                                  'Out-of-Scope Changes', 'Validation Evidence', 'Final Result'),

FIXED_PROTECTED = {
    'src/customer_search/data.py', 'TASK_UNDER_TEST.md', 'docs/EXPERIMENT_PROMPT.txt',
    'results/evidence/source-provenance.json', 'results/evidence/audit-before.json',
    'results/evidence/functional-baseline.json',
}
ALLOWED_LOCAL = {
    'models': set(), 'data': {'models'}, 'search': {'models'},
    'cli': {'data', 'search'}, '__main__': {'cli'}, '__init__': {'models', 'search'},
}


def visible_markdown(text: str) -> str:
    """I exclude fenced examples and comments from heading/reference validation."""
    text = re.sub(r'<!--.*?(?:-->|\Z)', '', text, flags=re.S)
    lines = []
    fence = None
    width = 0
    for line in text.splitlines():
        match = re.match(r'^ {0,3}(`{3,}|~{3,})(.*)$', line)
        if fence is None:
            if match:
                fence, width = match[1][0], len(match[1])
            else:
                lines.append(line)
        elif match and match[1][0] == fence and len(match[1]) >= width and not match[2].strip():
            fence = None
    return '\n'.join(lines)


def protected_paths(root: Path) -> set[str]:
    paths = set(FIXED_PROTECTED)
    for folder in ('results/prior', 'skills'):
        paths.update(str(p.relative_to(root)) for p in (root / folder).rglob('*') if p.is_file())
    return paths


def check(root: Path) -> list[str]:
    errors: list[str] = []
    text: dict[str, str] = {}
    for rel in ESSENTIAL:
        path = root / rel
        # I check every ancestor to prevent a directory symlink from redirecting a contract.
        chain = [root.joinpath(*Path(rel).parts[:i]) for i in range(1, len(Path(rel).parts) + 1)]
        if any(p.is_symlink() for p in chain):
            errors.append(f'symlink is forbidden for essential path: {rel}')
        if not path.is_file():
            errors.append(f'missing essential file: {rel}')
            continue
        try:
            content = path.read_text(encoding='utf-8')
            if not content.strip():
                errors.append(f'empty essential file: {rel}')
            text[rel] = content
        except (OSError, UnicodeError) as exc:
            errors.append(f'unreadable essential file: {rel}: {exc.__class__.__name__}')

    for rel, headings in HEADINGS.items():
        content = visible_markdown(text.get(rel, ''))
        found = re.findall(r'^## (.+?)\s*$', content, re.M)
        for heading in headings:
            if found.count(heading) != 1:
                errors.append(f'required unique heading missing/duplicated: {rel}: {heading}')
            else:
                body = re.split(r'^## ', content, flags=re.M)[found.index(heading) + 1]
                if not body.partition('\n')[2].strip():
                    errors.append(f'empty contract section: {rel}: {heading}')

    for rel in ('AGENTS.md', 'docs/REPO_MAP.md'):
        for source in ('REQUIREMENTS.md', 'SPEC.md', 'ARCHITECTURE.md', 'TASKS.md'):
            if source not in visible_markdown(text.get(rel, '')):
                errors.append(f'missing source-of-truth reference: {rel}: {source}')
    for rel in ('README.md', 'docs/REPO_MAP.md'):
        for target in re.findall(r'\[[^\]]+\]\(([^)]+)\)', visible_markdown(text.get(rel, ''))):
            if re.match(r'^[a-zA-Z][\w+.-]*:', target) or target.startswith('#'):
                continue
            path = ((root / rel).parent / target.split('#')[0]).resolve()
            if not path.is_relative_to(root) or not path.is_file():
                errors.append(f'broken or escaping local link: {rel}: {target}')

    task = visible_markdown(text.get('TASK_UNDER_TEST.md', ''))
    if len(re.findall(r'^Change ID: CR-[A-Z0-9-]+\s*$', task, re.M)) != 1:
        errors.append('task must have one explicit Change ID')
    for prefix, source in (('FR', 'REQUIREMENTS.md'), ('AC', 'SPEC.md')):
        known = set(re.findall(r'\b' + prefix + r'-\d{2}\b', text.get(source, '')))
        references = set(re.findall(r'\b' + prefix + r'-\d{2}\b', task))
        if not references or not references <= known:
            errors.append(f'task has missing or unresolved {prefix} references')

    try:
        manifest = json.loads(text.get('docs/protected-paths.json', '{}'))
        expected = protected_paths(root)
        entries = manifest.get('files', {})
        if manifest.get('schema_version') != 1 or set(entries) != expected:
            errors.append('protected manifest must cover exactly all declared protected paths')
        for rel, digest in sorted(entries.items()):
            path = root / rel
            ancestors = [root.joinpath(*Path(rel).parts[:i]) for i in range(1, len(Path(rel).parts) + 1)]
            if Path(rel).is_absolute() or '..' in Path(rel).parts or any(p.is_symlink() for p in ancestors):
                errors.append(f'unsafe protected path: {rel}')
            elif not path.is_file() or hashlib.sha256(path.read_bytes()).hexdigest() != digest:
                errors.append(f'protected file changed or missing: {rel}')
    except (OSError, ValueError, TypeError, AttributeError):
        errors.append('invalid protected manifest')

    for rel in ('.env', 'id_rsa', 'id_ed25519', 'credentials.json'):
        if os.path.lexists(root / rel):
            errors.append(f'forbidden sensitive root path: {rel}')
    for path in (root / 'src').rglob('*'):
        if path.is_symlink():
            errors.append(f'symlink in source: {path.relative_to(root)}')

    try:
        config = tomllib.loads(text.get('pyproject.toml', ''))
        if config.get('project', {}).get('dependencies') != []:
            errors.append('runtime dependencies must remain empty')
        if config.get('tool', {}).get('pytest', {}).get('ini_options', {}).get('testpaths') != ['tests']:
            errors.append('pytest must target active tests only')
    except (ValueError, TypeError):
        errors.append('invalid pyproject.toml')

    for module, allowed in ALLOWED_LOCAL.items():
        path = root / 'src/customer_search' / f'{module}.py'
        try:
            tree = ast.parse(path.read_text(encoding='utf-8'))
            for node in ast.walk(tree):
                names = []
                if isinstance(node, ast.Import):
                    names = [alias.name for alias in node.names]
                elif isinstance(node, ast.ImportFrom):
                    if node.level:
                        if node.level != 1 or not node.module or node.module.split('.')[0] not in allowed:
                            errors.append(f'architecture dependency violation: {module}: relative import')
                    elif node.module:
                        names = [node.module]
                for name in names:
                    base = name.split('.')[0]
                    if base == 'customer_search':
                        local = name.split('.')[1] if '.' in name else None
                        if local not in allowed:
                            errors.append(f'architecture dependency violation: {module}: {name}')
                    elif base not in sys.stdlib_module_names:
                        errors.append(f'nonstandard runtime import: {module}: {name}')
                if module in {'models', 'search'}:
                    if names and any(n.split('.')[0] in {'os', 'sys', 'pathlib', 'subprocess', 'socket', 'urllib', 'http', 'io'} for n in names):
                        errors.append(f'domain I/O dependency violation: {module}')
                    if isinstance(node, ast.Call) and isinstance(node.func, ast.Name) and node.func.id in {'print', 'open', 'input', 'exec', 'eval', '__import__'}:
                        errors.append(f'domain side-effect call: {module}: {node.func.id}')
        except (OSError, SyntaxError, UnicodeError):
            errors.append(f'unreadable or invalid runtime module: {module}')

    try:
        workflow = yaml.load(text.get('.github/workflows/verify.yml', ''), Loader=yaml.BaseLoader)
        if workflow['permissions'] != {'contents': 'read'}:
            errors.append('CI permissions must be contents: read only')
        if not {'push', 'pull_request'} <= set(workflow['on']):
            errors.append('CI must independently run on push and pull_request')
        steps = workflow['jobs']['verify']['steps']
        if not any(s.get('run') == './scripts/verify_repo.sh' for s in steps):
            errors.append('CI must invoke the single shared verification script')
        if any(re.search(r'\bpytest\b|\bruff check\b|check_repo_contract\.py', s.get('run', '')) for s in steps):
            errors.append('CI must not duplicate gate stage logic')
    except (KeyError, TypeError, AttributeError, yaml.YAMLError):
        errors.append('invalid CI workflow structure')

    verify = text.get('scripts/verify_repo.sh', '')
    for required in ('set -euo pipefail', '-m pytest', '-m ruff check', 'scripts/check_repo_contract.py'):
        if required not in verify:
            errors.append(f'verification script missing stage/safety marker: {required}')
    script = root / 'scripts/verify_repo.sh'
    if script.is_file() and not script.stat().st_mode & stat.S_IXUSR:
        errors.append('verification script must be executable')
    return sorted(set(errors))


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument('--root', type=Path, default=ROOT)
    args = parser.parse_args(argv)
    errors = check(args.root.resolve())
    if errors:
        for error in errors:
            print(f'CONTRACT: FAIL: {error}', file=sys.stderr)
        return 1
    print('CONTRACT: PASS (files, headings, references, protected hashes, boundaries, CI)')
    return 0


if __name__ == '__main__':
    raise SystemExit(main())
